# Cierre de Instanashelock v1.0.0

Registro historico de un hito local pre-open-source. No representa una release
publica ni un tag importado al nuevo repositorio OSS.

`Instanashelock v1.0.0` queda cerrada como una build local seria para uso personal.

## Que incluye

- vault local cifrado
- recovery codes opcionales
- guardado atomico + backup local
- deteccion de conflictos entre instancias
- restore desde `.bak`
- export / restore de respaldo cifrado portable
- build local e instalador verificados

## Que no incluye

- nube propia
- sync entre dispositivos
- notas seguras avanzadas y documentos como eje principal del producto
- firma de codigo
- publicacion en Microsoft Store

## Decision de producto

Esta linea `v1` se mantiene estable y util para guardar passwords de uso real sin contaminarla con el rework grande.

`Instanashelock 2.0` queda reservado para:

- rediseño fuerte de UX
- expansion a notas seguras, documentos y otros tipos de item
- evolucion de arquitectura sin arrastrar decisiones visuales de `v1`
